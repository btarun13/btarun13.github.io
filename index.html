About

I turn complex biological and chemical data into things you can act on. Most of my work sits where networks, AI, software design and mathematics overlap: building GNN-powered epigenetic models, writing open-source packages for graph-based drug repurposing, and setting up retrieval pipelines so domain experts can query the literature in plain language.

Recently: a RAG pipeline on Pinecone over drug literature, a drug–disease recommender built on graph embeddings, and visibility graphs for turning time series into networks.

Selected projects

  • GDC-Mutant-Peptide-Explorer

    For a given cancer, which mutant antigens would make the best vaccine targets? A Streamlit app that pulls open-access somatic mutation data from the NCI GDC, rebuilds mutant and wild-type peptides, and predicts HLA class I binding with MHCflurry, with a funnel, recurrence view and full provenance on every export.

    Python · Streamlit

  • visibility_graph

    Builds graph embeddings for time-series data by converting sequences into visibility graphs, so standard network methods apply to signals.

    Jupyter · Python

  • drug_repurposing

    A pipeline that learns graph embeddings over a biomedical knowledge graph and uses them to predict candidate drug–disease associations.

    Python

  • Regulatr-app

    Hackathon submission: a web app that links ENCODE experiments by accession ID so you can explore the regulatory context of non-coding variants.

    Python

  • Search_Vector_DB_RAG

    Searches and downloads papers for specific drugs (from SMILES), indexes them into a Pinecone vector database, and exposes a RAG command-line interface.

    Jupyter · Python

  • redpanda

    Molecular classifier that predicts the clinical activity of drug candidates from their structure.

    Jupyter · Python
